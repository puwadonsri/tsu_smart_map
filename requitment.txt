# ข้อกำหนดแอปพลิเคชัน TSU Smart Map (ปรับปรุง 2569)

แอปเมนูและฟีเจอร์หลัก (App Features)
โดยยังไม่ต้องเชื่อมต่อฐานข้อมูล (No DB) — ข้อมูลทั้งหมดถูกกำหนดผ่าน config file
เพื่อให้สามารถปรับแก้ได้โดยไม่ต้องแก้โค้ด

## 1. แผนที่อัจฉริยะ (Interactive Map)
- แสดงแผนที่บริเวณมหาวิทยาลัยทักษิณ วิทยาเขตพัทลุง (ต.บ้านพร้าว อ.ป่าพะยอม จ.พัทลุง)
- พิกัดศูนย์กลางเริ่มต้น: 7.80822, 99.93869 (ปรับได้ใน config)
- แผนที่ใช้ OpenStreetMap (ไม่ต้องใช้ API key / ใช้งานฟรีทั้งหมด)
- แตะที่ Marker เพื่อดูรายละเอียดจุด และกด "นำทางไป Google Maps"
  เพื่อเปิดเส้นทางจากตำแหน่งผู้ใช้ไปยังจุดนั้น (ใช้ URL ทั่วไป ไม่ต้องใช้ API key)
- มีช่องค้นหาด้านบน (Search) กรองชื่อจุด/ตลาด แล้วเลื่อนแผนที่ไปยังจุดที่เลือก

## 2. Filter Layers — เปิด-ปิด การแสดงผลบนแผนที่ แบ่งเป็น 4 ประเภท:
- 🚎 จุดรถราง: ตำแหน่งศาลาที่รถรางจอด
- ⛽ จุดเติมน้ำมัน: ปั๊มน้ำมันสวัสดิการหรือจุดเติมใกล้เคียง
- 🛴 จุดสกู๊ตเตอร์: พื้นที่จอดและเช่าสกู๊ตเตอร์ไฟฟ้า
- ⚠️ จุดควรระมัดระวัง: ทางแยกที่เกิดอุบัติเหตุบ่อย หรือจุดที่ไฟส่องสว่างน้อย

เปิด-ปิดได้ 2 ทาง:
- แถบด้านข้าง (Drawer) → "ตัวกรองชั้นข้อมูล" มีสวิตช์ทุกประเภท
- ปุ่มลัดด้านล่าง (Shortcut) เช่น ปุ่ม "จุดรถราง" กดเพื่อสลับเปิด-ปิดชั้นข้อมูลนั้น
  (ปุ่มลัดกำหนดได้ใน config ผ่านส่วน shortcuts)

## 3. Emergency Call — ปุ่มโทรออกฉุกเฉิน
- เบอร์โทรฉุกเฉิน (default): 0928733748 (ปรับได้ใน config)
- เข้าถึงได้จากปุ่มลัดด้านล่าง "เบอร์ฉุกเฉิน" และปุ่มสีแดงลอย (FAB) มุมขวาล่าง
- จะแสดงหน้าจอยืนยันสีแดง พร้อมปุ่ม "กดโทรออก" — ใช้สำหรับรถเสีย / อุบัติเหตุ

## 4. Nearby Markets — รายชื่อตลาดรอบมหาวิทยาลัย
- แสดงรายชื่อตลาด เช่น ตลาดป่าพะยอม, ตลาดนัดหน้ามอ (เพิ่ม/แก้ได้ใน config)
- แสดงระยะทางโดยประมาณ + คำอธิบายสั้น ๆ
- กดที่การ์ดตลาดเพื่อนำทางไปยังตลาดนั้นใน Google Maps

## 5. การออกแบบ UI (User Interface)
- หน้าเปิด (Splash Screen) สีฟ้า แสดงชื่อแอป แล้วเข้าสู่หน้าแผนที่
- หน้าแรก: แผนที่เต็มหน้าจอ + แถบค้นหาสีขาวมนด้านบน
- แถบด้านล่าง (Bottom Bar): ปุ่มทางลัด 3 ปุ่ม คือ "ตลาดใกล้ฉัน", "เบอร์ฉุกเฉิน", "จุดรถราง"
- แถบด้านข้าง (Sidebar/Drawer): เลือกประเภทสถานที่ที่ต้องการให้โชว์บนแผนที่
- ธีมสีหลัก: น้ำเงินเข้ม (#0D47A1)

## 6. การจัดการข้อมูล (Config-driven)
- ไฟล์ข้อมูลกลาง: `assets/config/app_config.json`
  - app: ชื่อแอป, ชื่อวิทยาเขต, เบอร์ฉุกเฉิน, คำอธิบาย
  - map: พิกัดศูนย์กลาง, ระดับซูม
  - layers: แต่ละประเภทสถานที่ + รายการจุด (name, lat, lng, detail)
  - markets: รายการตลาด (name, lat, lng, detail, distanceKm, emoji)
  - shortcuts: ปุ่มลัดด้านล่าง (label, icon, color, action)
- โหมดเว็บ (Web build): ระบบโหลด config จากไฟล์ภายนอก `config/app_config.json`
  ที่อยู่ข้างตัว build ทำให้แก้ข้อมูลแล้วกดรีเฟรชได้ทันทีโดยไม่ต้อง compile ใหม่
  (ถ้าไม่มีไฟล์ภายนอก จะใช้ config ที่ฝังมาในตัวแอป)

## เทคโนโลยี
- Flutter (เวอร์ชันที่ใช้พัฒนา: 3.47.2 stable) — รันได้บน Web / Windows / Android
- แผนที่: flutter_map + OpenStreetMap (ไม่ต้องใช้ API key)
- เปิดแผนที่นำทาง: url_launcher -> google.com/maps/dir
- โหลด config ภายนอก: package http

## หมายเหตุ (ทางเลือกถ้ามี Google Maps API key)
- ปัจจุบันใช้ OpenStreetMap ฟรี โดยไม่ต้องตั้งค่าใด ๆ
- ถ้าต้องการแผนที่ Google Maps แทน แนะนำใช้ package google_maps_flutter
  แล้วใส่ API key ใน config/ระบบตาม document ของ Google Maps Platform
